# Materiais de apresentação

Materiais de feira organizados por evento. `feicit/` contém os arquivos já
existentes; [mostratec/](mostratec/README.md) contém um complemento curto sobre
o valor do gateway, com fala e pequenos acréscimos propostos aos materiais.

- [Painel de resultados](feicit/paineis/painel-resultados.html): painel HTML
  preservado nesta cópia. A organização não valida novamente seus cálculos
  ou conclusões.
- `feicit/banners/`: três PDFs, identificados por posição.
- [Tabela de resultados do MCP Sentry](mostratec/README.md#tabela-de-resultados-do-mcp-sentry):
  versões SVG, PNG e PDF, organizadas junto aos materiais da MOSTRATEC.

O painel é um HTML independente, com conteúdo incorporado. Esta pasta não
armazena logs de execução; os resultados científicos ficam em `pesquisa/`.
