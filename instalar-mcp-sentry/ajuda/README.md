# Ajuda do MCP Sentry

Para instalar, leia o `README.md` da pasta extraída do ZIP.

| O que deseja fazer | Guia |
| --- | --- |
| Usar, revisar um bloqueio ou atualizar | [Uso e atualização](USO-E-ATUALIZACAO.md) |
| Resolver um erro | [Solução de problemas](SOLUCAO-DE-PROBLEMAS.md) |
| Configurar manualmente ou usar outro cliente | [Configuração](CONFIGURACAO.md) |
| Definir critérios de privacidade para revisão | [Privacidade](PRIVACIDADE.md) |

Na instalação nova, o programa fica em `%LOCALAPPDATA%\MCP-Sentry-Gateway`.
Uma cópia destes guias fica em `ajuda-mcp-sentry`, junto ao ambiente instalado.
O resumo da instalação mostra os caminhos efetivos. Se você usa uma
instalação antiga ou um ambiente escolhido manualmente, siga esses caminhos.
